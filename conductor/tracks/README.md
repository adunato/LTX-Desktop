# Tracks Directory

This directory contains individual feature tracks, each with their own specification and implementation plan.

## Track Structure

Each track folder should contain:
- `spec.md` - Track specification and requirements
- `plan.md` - Implementation plan
- `metadata.json` - Track metadata (status, dates, etc.)
- `index.md` - Track index (optional, links to other track documents)

## Creating a New Track

1. Create a new directory with a kebab-case track ID: `tracks/<track_id>/`
2. Add the required files (spec.md, plan.md, metadata.json)
3. Register the track in `../tracks.md`
